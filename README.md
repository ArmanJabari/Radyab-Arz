
# Introduction

This script fetches real-time buy and sell prices for 28 currencies from [Alanchand.com](https://alanchand.com) in `Iranian Toman`. It uses `requests` to access the website and `BeautifulSoup` to parse the data, presenting prices in a clear table. The output updates every minute, refreshing the console display. Its purpose is to provide users with up-to-date currency exchange rates in Toman effortlessly.

# Installation
1. **Clone the Repository**  

   ```bash
   git clone https://github.com/ArmanJabari/Radyab-Arz
   ```

2. **Navigate to the Project Directory**  

   ```bash
   cd Radyab-Arz
   ```

3. **Install the Libraries**  

   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Script**  
   
   ```bash
   python main.py
   ```
